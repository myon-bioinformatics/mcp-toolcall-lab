Runtime, evidence and limits

The browser imports the very same JavaScript module used by the Node CLI and Python→Node bridge. Node→Python adapter lookup calls the existing integrity-checked engine_adapter. No Python runtime, MCP server, Docker service or model is hosted on Pages.


Confidence stays unknown unless explicitly present in an input record. Recorded probabilities are separately attributed by line and prob_source, never presented as calibrated confidence in these metrics.


The public example executes deterministic mock catalog functions during the build and records them through the lab's shared logger. It is not an MCP transport or external API test.
